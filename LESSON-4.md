# LESSON-4 - Управление формами в React

Ветка: lesson-4

## Запуск

```bash
npm ci && npm run dev
npm run build
npm run lint
```

## Чеклист

- Форма регистрации реализована на React Hook Form - 1 балл
- Все обязательные поля валидируются - 1 балл
- Email, пароль и подтверждение пароля проверяются корректно - 1 балл
- Ошибки отображаются рядом с полями - 1 балл
- Валидация вынесена в Zod-схему и подключена через `zodResolver` - 2 балла
- Социальные ссылки управляются через `useFieldArray` - 1 балл
- Добавление и удаление ссылок работает без ошибок - 2 балла
- Каждая социальная ссылка валидируется как URL - 1 балл
- Двухшаговая форма подписки реализована через `useActionState` - 1 балл
- В wizard отображаются состояния pending, error и success - 1 балл
