# LESSON-8 - React Portal

Ветка: `lesson-8`

## Что сделано

- Добавлен универсальный Tooltip с четырьмя вариантами позиции.
- Tooltip появляется при наведении и рендерится через `createPortal`.
- События продолжают всплывать до родительского элемента.
- Стили портала изолированы через CSS Modules.
- Добавлен ConfirmDialog с кастомным заголовком и описанием.
- Результат диалога возвращается через Promise.
- Добавлена демонстрационная страница `/portals`.
- Контекст светлой и темной темы сохраняется внутри обоих порталов.

## Как запустить

```bash
npm install
npm run dev
```

Проверка проекта:

```bash
npm run lint
npm run build
```
