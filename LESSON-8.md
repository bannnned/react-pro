# Домашнее задание 8

## Как запустить

```bash
npm install
npm run dev
```

## Чеклист

- Tooltip рендерится через портал
- Поддерживаются четыре позиции
- События всплывают до родительского элемента
- Стили изолированы через CSS Modules
- ConfirmDialog возвращает результат через Promise
- Заголовок и описание передаются через props
- Тема из контекста работает внутри порталов
