# DogFood

Учебный магазин лакомств для собак на React 19 и TypeScript.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm ci
npm start
```

Откройте http://127.0.0.1:4173. Демо-вход: `demo@dogfood.test`, пароль `Dogfood19!`. Локальный API хранит данные в памяти до перезапуска.

## Что сделано

- Вход, регистрация, защищённые маршруты и редактирование профиля.
- Каталог с поиском через URL, сортировкой и подгрузкой при прокрутке.
- Карточки товаров, публикация отзывов, создание и удаление своих товаров.
- Корзина с подсчётом суммы и подтверждением удаления через `createPortal`.
- Оптимистичное избранное на `useOptimistic` с откатом при ошибке API.
- Сборки Webpack и esbuild.

## Структура папок

- `src/app` — маршруты, Redux store и каркас приложения.
- `src/pages` — экраны магазина.
- `src/features` — авторизация, каталог, корзина, поиск, избранное и отзывы.
- `src/shared` — общие компоненты, типы, HTTP-клиент и утилиты.
- `src/widgets` — шапка и подвал.
- `public` — HTML и изображения товаров.
- `scripts` — локальный API, демоданные, сборка esbuild и замер сборок.
- `webpack` — конфигурация Webpack.
