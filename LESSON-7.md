# Домашнее задание 7

## Как запустить

```bash
npm install
npm run build:hw
```

## Чеклист

- Приложение собирается через esbuild
- Для dev-сборки включен watch
- Библиотека собирается в ESM и CommonJS
- React не попадает в библиотечный бандл
- Неиспользуемые функции удаляются из сборки
- Маршруты загружаются через динамический импорт
- SWC собирает библиотеку в двух форматах
