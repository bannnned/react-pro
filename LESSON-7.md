# LESSON-7 - современная сборка

Ветка: `lesson-7`

## Что сделано

- Добавлена отдельная папка `build-hw` для задания.
- SPA собирается через esbuild с минификацией, sourcemap и tree shaking.
- Страницы загружаются через динамический `import` и попадают в отдельные чанки.
- Библиотека собирается из трех entry points в форматах ESM и CommonJS.
- React и другие внешние зависимости исключены из бандла.
- Добавлен dev-режим без минификации и с watch.
- Добавлена отдельная сборка библиотеки через SWC в двух форматах.

## Как запустить

```bash
npm install
npm run build:hw
```

Dev-режим приложения:

```bash
npm run dev:hw:app
```

Обычная проверка проекта:

```bash
npm run lint
npm run build
```
