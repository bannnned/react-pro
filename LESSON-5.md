# LESSON-5 - useRef и работа с DOM

Ветка: `lesson-5`

## Что сделано

- Добавлен таймер кликов с сохранением времени первого нажатия и счетчика в `useRef`.
- Добавлено поле, которое показывает предыдущее значение после изменения текста.
- Добавлено управление фокусом между двумя полями и подсчет переходов.
- Добавлен отложенный вывод текста в консоль через одну секунду после остановки ввода.
- Добавлено WebSocket-подключение с выводом входящих сообщений в консоль.
- Все примеры собраны на отдельной странице.

## Как запустить

```bash
npm install
npm run dev
```

Проверка проекта:

```bash
npm run lint
npm run build
```

## Чеклист

- Время первого клика хранится в `useRef` - 1 балл
- Количество кликов хранится в `useRef` - 1 балл
- В консоль выводятся время и номер клика - 1 балл
- Предыдущее значение поля хранится в `useRef` - 1 балл
- Ссылка обновляется через `useEffect` - 1 балл
- Предыдущее значение показано под полем - 1 балл
- Первое поле получает фокус по кнопке - 1 балл
- Переходы между полями считаются через `useRef` - 1 балл
- Первый фокус не считается переходом - 1 балл
- Таймер отложенного вывода хранится в `useRef` - 1.5 балла
- WebSocket хранится в `useRef` и закрывается при размонтировании - 1.5 балла
