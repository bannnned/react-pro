# Домашнее задание 9

## Чеклист

- Форма сохранения реализована через `useActionState`
- Во время запроса отображается состояние загрузки
- После успешного сохранения поле формы очищается
- Оптимистичный список реализован через `useOptimistic`
- Новая задача появляется до завершения запроса
- После ответа сервера задача не дублируется
- Дополнительная форма использует reducer внутри `useActionState`
- Несколько полей обрабатываются одним action
- После отправки поля дополнительной формы очищаются
